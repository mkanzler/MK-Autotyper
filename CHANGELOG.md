# Changelog

## 2.0

- Redesigned native UI/icon, light/dark/system themes and matching dialogs.
- Searchable snippets with configurable shortcuts and master-password protection.
- One JSON collection with Unicode/symbol display names independent of filenames.
- Full editor commands, per-user preferences, delays and tray-only startup.
- Shared clipboard start/stop shortcut, progress and cancellation.
- Consistent input events for English US/UK and German layouts.
- Portable x64/x86 EXE and ZIP downloads and expanded regression tests.

See the [release notes](docs/releases/v2.0.md) for downloads and supported behavior.
