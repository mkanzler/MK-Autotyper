# Changelog

## 2.1

- Native card editor for text, keys, shortcuts and pauses, with growing text fields, expandable cards and drag-and-drop ordering.
- Friendly key search, labeled shortcut recording and keyboard step ordering.
- Opt-in fill-in variables, repeated field values and local date/time placeholders.
- Per-snippet input mode and delay overrides, with global settings as the default.
- Optional first-use session unlock for encrypted snippets, with explicit locking.
- German scan-code `@` now uses left Ctrl + left Alt + Q instead of right Alt/AltGr.
- Fixed stale resize fragments, scroll jumps, outside/stale-position drops, drag interruptions and undo loss when folding text.
- Text editors adapt to window height; wheel scrolling follows Windows settings and long previews indicate how to edit them.
- Fixed invalid pause values blocking their card menu and enforced the total text limit when committing a card.
- Updated README feature descriptions and light/dark screenshots of the card editor.

## 2.0

- Redesigned native UI/icon, light/dark/system themes and matching dialogs.
- Searchable snippets with configurable shortcuts and master-password protection.
- One JSON collection with Unicode/symbol display names independent of filenames.
- Full editor commands, per-user preferences, delays and tray-only startup.
- Shared clipboard start/stop shortcut, progress and cancellation.
- Consistent input events for English US/UK and German layouts.
- Portable x64/x86 EXE and ZIP downloads and expanded regression tests.

See the [release notes](docs/releases/v2.1.md) for downloads and supported behavior.
