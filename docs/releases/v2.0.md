# MK AutoTyper v2.0

Version 2.0 introduces a redesigned native Windows interface, searchable snippets and password-protected storage, while keeping distribution portable.

## Highlights

- Light, dark and Windows-following themes across the app and dialogs.
- Full editor commands: selection, undo/redo, context menu and keyboard navigation.
- Configurable global clipboard start/stop and searchable snippet shortcuts.
- A compact selector with live filtering, mouse/keyboard navigation and four visible results.
- Unicode/symbol snippet names and optional master-password encryption.
- Adjustable delays, countdown/progress, cancellation, per-user preferences and tray-only startup.
- Consistent `SendInput` events for supported English US/UK and German layouts, with scan-code and Unicode modes.

## Compatibility

Snippets are stored in `%LOCALAPPDATA%\MK-AutoTyper\Snippets.json` and `Encrypted.dat`.

Scan-code input remains the launch default. Theme, delays, global shortcuts and placement are saved per user; input-method selection is not persisted.

Text, Tab, Backspace and Enter/Shift+Enter line breaks are supported. Shortcut sequences and pause/resume are not available in v2.0.

Some destinations or elevated apps reject simulated input. Run both apps at the same permission level. Binaries are unsigned unless a publisher signature is applied separately; Windows may display a reputation warning.

## Protection and reliability

Protected snippets use Windows CNG AES-256-GCM and PBKDF2-HMAC-SHA-256. Passwords are requested per protected operation and are not cached. Owned decrypted data is cleared after typing finishes, stops or fails. See [security and storage](https://github.com/mkanzler/MK-Autotyper/blob/release-2.0/docs/security.md) for limitations.

Collection updates use flushed atomic replacement and serialized writers. Invalid names and malformed/unsupported files are rejected before saving. Tests cover mapping, native UI, parsing, concurrency, encryption/tampering and rollback.
