# MK AutoTyper v2.1

Version 2.1 adds a native card editor for action sequences, fill-in variables, per-snippet typing settings and optional session unlock for encrypted snippets.

## Highlights

- Build sequences from text, keys, shortcuts and timed pauses in the main window.
- Keep every step visible, expand key/pause cards to edit, and drag the grip to reorder. Alt+Up/Down provides keyboard ordering.
- Text fields grow with their contents and adapt to the available window height.
- Record shortcuts or search for keys, including a distinct Numpad Enter choice.
- Enable variables such as `{name}`, `{date}` and `{time}`. Repeated fields are entered once before typing.
- Save an input method and delays for an individual snippet, or keep using global settings.
- Optionally unlock encrypted snippets on first use, then lock them manually or exit to end the session.
- German scan-code `@` uses left Ctrl + left Alt + Q.
- Improved live resizing, wheel scrolling, drag cancellation, scroll anchoring and folding/undo behavior. Card commits enforce the combined text limit, and invalid pauses can still be removed.

## Typing and settings

English US/UK and German layouts are supported. Scan-code input remains the launch default. Theme, delays, shortcuts, window placement and the session-unlock preference are saved per user. Per-snippet typing overrides apply only to that snippet.

**Ctrl+Alt+V** types clipboard text or stops the current session. **Ctrl+Alt+P** searches saved snippets. Both global shortcuts are configurable. Closing the window keeps the app in the tray; use **Exit** to close it completely.

Playback remains cancellable during pauses and stops if the destination window or keyboard layout changes. Some destinations or elevated apps reject simulated input; run both apps at the same permission level. Binaries are unsigned unless signed separately, so Windows may show a reputation warning.

## Protected snippets

The complete action document, including its variables and typing settings, is encrypted using Windows CNG AES-256-GCM and PBKDF2-HMAC-SHA-256. The password is never cached. Session unlock is optional and off by default; it retains only a process-protected derived key. Closing to the tray, Windows lock and sleep keep that session unlocked. Use **Lock encrypted snippets** or **Exit** to clear it.

Owned decrypted editor content and undo history are cleared when a protected typing attempt finishes, stops or fails. Expanded variable values are not saved back to the snippet. Windows controls and destination apps can retain copies outside the app's owned buffers; see [security and storage](https://github.com/mkanzler/MK-Autotyper/blob/release-2.1/docs/security.md).

Snippets remain in `%LOCALAPPDATA%\MK-AutoTyper\Snippets.json` and `Encrypted.dat`.
